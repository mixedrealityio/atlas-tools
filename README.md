# atlas-tools

Sources et scripts des atlas servis sur le VPS (dépôt privé de sauvegarde).

- `ia/` : Atlas de l'IA — `content_*.py` décrit chaque chapitre ; `build.py` génère le site dans `~/atlas-ia-upstream` (dépôt public mixedrealityio/atlas-de-l-ia) ; `covers.py`, `shot.py`, `check.py`, `overflow.py` pour vignettes et contrôles.
- `3d/` : Atlas de la 3D.
- `ingenieur/` : Atlas de l'ingénieur IA.
- Scripts du site : `atlas-update.py` (synchro quotidienne), `atlas-push.py`, `atlas_translate.py`, `make-equations.py`, etc.
